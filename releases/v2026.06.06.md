### 🟢 Utils API Token — Green Dot Fix (Hotfix)
- Fixed: API auth token (green/red dot on home page) was always showing red after login
- **Root cause:** With ASP.NET StateServer session mode, the background thread that fetched the utils JWT token wrote directly to `Session` — but StateServer serializes the session at request end, before the background thread completed. The token write was lost on every login.
- **Fix:** Background thread now returns tokens via `ref` params. Main request thread sets `Session["schedular_access_token"]` after `thread.Join(3000)`, ensuring StateServer captures the token correctly.
- Added `WebRequest.Timeout = 2500ms` so a slow/down utils server does not block the login for more than ~3 seconds.
