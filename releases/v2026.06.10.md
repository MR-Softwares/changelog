## 🏫 ERP Server (School Side)
> Deployed: 10-06-2026 | Previous: 01-06-2026

### 🔬 OpenTelemetry + MySqlConnector Migration (Infrastructure)
Major under-the-hood infrastructure upgrade — no user-visible functional change, but significant for reliability and observability:

**MySQL Driver replacement (MySql.Data → MySqlConnector)**
- Removed Oracle `MySql.Data.dll` v6.8.8; replaced with `MySqlConnector.dll` v2.3.7
- MySqlConnector is fully async-native, has better connection pool behavior, and avoids several known deadlock edge cases
- New `MySqlConnectorMembershipProvider.cs` and `MySqlConnectorRoleProvider.cs` handle login/role checks via the new driver
- `MySqlHelper.cs` added: retry wrapper for transient failures
- `web.config` updated: membership/roleManager providers, DbProviderFactory, binding redirects

**OpenTelemetry distributed tracing**
- 14 new DLLs added: full OpenTelemetry stack (API, SDK, OTLP exporter, ASP.NET & HTTP instrumentation, Microsoft.Extensions.* dependencies)
- `Global.asax`: TracerProvider bootstrapped at startup, exporting via HTTP/Protobuf to collector at `192.168.10.196:4318` (skynet)
- `OtelHelper.cs`: tag-method helper used across 667 call sites in `secureAPI.asmx`
- `CorrelationDbHelper.cs`: DB query helper that propagates trace context
- All 37 `App_Code` modules migrated from `MySql.Data.MySqlClient` → `MySqlConnector` namespace

**GitHub sync workflow updated**
- `sync.yml`: added Step 4 — bidirectional `secureAPI.asmx` sync between schoolside and cloudside (same conflict-detection guard as existing App_Code sync step)

### 🔐 Login — Scheduler Token Race Condition Fix
- Fixed a session loss bug on StateServer where the scheduler background token thread could race with the redirect
- Token is now set in the main thread after the background thread joins, ensuring the session cookie is always written before the browser is redirected
- Eliminates random "logged out immediately after login" reports on StateServer deployments

### 💳 Fee Payment — Pay Mode Order Fix (Hotfix T18248)
- Fixed ordering of payment modes on the fee payment screen
- Modes now appear in the configured priority sequence instead of an arbitrary database insertion order

### 📊 Contra Voucher — Full Overhaul
Comprehensive rework of the Contra Voucher module (accounting):
- Insert bug fixed: `VHID` now correctly set to `NULL` when `voucher_type` is 0 or empty, avoiding FK constraint violations
- Submit button fixed: removed `btn.form.submit()` pattern that was silently swallowing `__doPostBack` — vouchers now save reliably
- Balance validation added: debit/credit totals must balance before submit is allowed
- UI rebuilt: cleaner layout, clearer validation error display
- Date filter leak in Voucher Daybook fixed: filters no longer bleed between column-wise and row-wise views
- Sort order in Voucher Daybook corrected for both view modes
- Income & Expenditure report: Expenditure column now shown before Income; Contra entries excluded from I&E totals (correct accounting treatment)
- Import Vouchers page (`Import_Vouchers.aspx.cs`) added for bulk voucher import via Excel
- Contra voucher attachment upload supported

### ⚡ Performance — DATE() Column Sargability Fix
- `lms.cs` and `Visitor_info.cs`: `DATE(column) = @date` predicates replaced with `column >= @start AND column < @end` range operators
- MySQL can now use indexes on those date columns; previously every such query forced a full table scan

### 🗄️ DB Migration — `_fee_pay_online` TxnDt Index (SQL #738)
- Idempotent migration script `738_v004_idx_fee_pay_online_txndt.sql` adds `idx_txndt` index on `_fee_pay_online.TxnDt`
- Speeds up date-range fee payment queries; skips silently if already present
