## 🏫 ERP Server (School Side)
> Deployed: 29-06-2026 18:41:42 IST | Previous: 06-06-2026 17:41 IST

### 💥 Class Teacher & Duty Pages — Crash on Board Names with Apostrophes (Hotfix)
- Fixed: Staff Shift, Class Subject Duties, Class Teacher assignment, Manage Salary, Teacher Duties, and Teacher Duties Report pages could all crash for schools/boards whose name contains an apostrophe (e.g. names like `Shri Shivaji's Board`)
- **Root cause:** These pages build an in-memory filter expression using the board's name directly. An apostrophe in the name broke the filter syntax and threw an error, taking the whole page down.
- **Fix:** Board names are now safely escaped before being used in the filter, so names with apostrophes no longer crash these pages
- Affects: `staff_shift`, `class_subject_duties`, `class_teacher`, `staff_manage_salary`, `teacher_duties`, `teacher_duties_report`

### 📄 RPT-RN1 Scholastic Report — Optional Footer Total (Hotfix)
- Previously, the RPT-RN1 scholastic report card always printed a "Total" row at the bottom, whether the school wanted it or not
- A new **"Footer Total: Yes/No"** option has been added to the report designer screen, so schools can now choose whether the total row is shown
- Existing report designs (that don't yet have this setting saved) will keep behaving exactly as before — the total row still shows by default

### 🎓 TC (Transfer Certificate) DIY — Bulk Generation
- The self-service Transfer Certificate designer (TC DIY) can now generate certificates **in bulk** for multiple students at once, instead of one at a time
- Certificate viewer and generator screens were reworked to support selecting and processing a batch of students together
- Follow-up fix applied the same day for a bug found while testing the new bulk flow

### 🗓️ Last Attendance Date — Staff & Student Deactivation
- The "Activate/Deactivate Staff" and "Activate/Deactivate Scholar (Student)" screens now show and use the **last attendance date** as part of the deactivation logic
- Screen layout on both pages was also reorganized for clarity when deactivating a staff member or student

### 🧾 Fee Receipt — Wrong Admission Number Fix (Hotfix)
- Fixed: fee receipts could sometimes print the wrong admission/registration number for a student
- **Root cause:** the receipt lookup wasn't using the student's branch-specific registration number when one was available, so it could fall back to an incorrect number
- **Fix:** the branch registration number is now fetched and used correctly when generating the fee receipt

### 📑 Scholar Documents (Bonafide/Certificates) — Page Crash Fix (Hotfix)
- Fixed: the "Scholar Documents" bulk certificate generation screen could crash midway when generating documents for a full class
- **Root cause:** a student with a missing or invalid registration number in the selected list would stop the whole batch instead of being skipped
- **Fix:** the batch now skips students with invalid registration numbers instead of failing, and the class-selection panel is shown correctly when generating for a whole class
- Follow-up fix applied a few days later to correct additional edge cases found in testing

### 💳 GrayQuest Auto-Debit — Tracking & Maintenance Pages
- Two new screens added for managing GrayQuest auto-debit installment plans:
  - **Auto Debit Maintenance** — configure and maintain auto-debit setup per school
  - **Auto Debit Tracking** — track the status of individual auto-debit installments
- Supporting database table (`739_GQ_Auto_Debit_installment_table`) added to store installment-level auto-debit data
- Minor related fix to the eSchoolPay report

### 🔄 Routine Sync
- Several automated `App_Code` and `secureAPI.asmx` syncs were applied from the Cloud Side codebase throughout this period to keep shared backend code consistent between ERP and Cloud Side
- One synced change (MySqlConnector/OpenTelemetry-related `App_Code` files) was reverted on 17-06-2026 as it was not yet ready for production
