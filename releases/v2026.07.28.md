# v2026.07.28 - Production Deployment

**Date:** 28 July 2026

---

## ☁ APP Server (Cloud Side)
> Deployed: 28-07-2026 18:02:03 IST | Previous: 15-07-2026 15:24 IST

**Improved system reliability and reduced unexpected outages.** The database connection layer was replaced with a modern, actively-maintained component. This resolves an issue that had been causing the application to unexpectedly restart under certain network conditions, and improves stability of API calls used by the mobile app and school portal.

**Added performance monitoring.** The system now records detailed timing and diagnostic information for every request behind the scenes. This will let our team spot and diagnose slowdowns or errors much faster going forward, without needing to reproduce issues after the fact.

**Login and permissions system rebuilt on the new foundation.** User authentication and role-based access (staff, admin, parent logins, etc.) were re-implemented to work with the updated database layer. Behavior is unchanged for end users — this was an internal foundation change with no visible difference to how logins work.

**Security updates.** Several underlying software libraries were updated to patch known security vulnerabilities, including components used for payment/SMS communication and data handling. No user action is required.

**Other fixes included in this release:**
- Corrected an issue where duplicate payment gateway notifications could trigger false alert emails to the finance team.
- Performance improvement to attendance and visitor-log reports for schools with large record volumes.
- General stability and compatibility fixes to support the above changes, including handling of scheduled/background tasks so a failure in one no longer risks affecting the whole application.

## 🏫 ERP Server (School Side)
> Deployed: 28-07-2026 19:30 IST | Previous: 17-07-2026 18:19 IST

**Improved system reliability and reduced unexpected outages.** The database connection layer was replaced with a modern, actively-maintained component — the same reliability upgrade rolled out to the Cloud side earlier today, now extended across all school sites. This resolves an issue that had been causing intermittent restarts under certain network conditions.

**Added performance monitoring.** The system now records detailed timing and diagnostic information for every request behind the scenes, letting our team spot and diagnose slowdowns or errors much faster, without needing to reproduce issues after the fact.

**Login and permissions system rebuilt on the new foundation.** User authentication and role-based access (staff, admin, student/parent logins, etc.) were re-implemented to work with the updated database layer. Behavior is unchanged for end users.

**Security updates.** Underlying software libraries were updated to patch known security vulnerabilities. No user action is required.

**Transfer Certificate (TC) improvements.** Fixed serial number and book number handling for both single and bulk TC generation, and added the ability to soft-delete a TC (recoverable, rather than a permanent delete) so mistakes are easier to correct.

**Other fixes and improvements included in this release:**
- Fixed an issue where admissions and lesson-plan log entries could fail to save correctly.
- Fixed issues in the user management and staff salary note screens.
- Added PDF preview so generated documents can be checked before printing/downloading.
- UI fixes on the auto-debit fee tracking pages.
- Performance improvement to attendance and visitor-log reports for schools with large record volumes.
- General stability and compatibility fixes to support the above changes.
